# ADR-0001: Business case and scope

Status: accepted (2026-10-17)

## Context

The assignment asks for a small working project in which an AI agent solves a realistic business case end to end: multi-step orchestration, at least two tools, structured output plus a readable summary, guardrails, observability, tests, and an honest account of real-world usage. The case had to be marketing-flavoured (the project is for Bulls Media), without claiming knowledge of any internal system.

## Options considered

| Case | Verdict |
|---|---|
| Affiliate-traffic fraud scoring | Rejected. In a demo the ground truth is unknowable, so conclusions cannot be checked. |
| Budget-pacing alerts | Rejected. Mostly arithmetic and thresholds; no investigation path that depends on intermediate evidence. |
| Creative-fatigue analysis | Rejected. One dominant signal (CTR decay); little for an agent to decide. |
| Postback / tracking QA alone | Kept as one tool family, not the whole case: it is only one of the possible causes. |
| **Conversion-rate drop: root-cause investigation** | **Chosen.** |

## Decision

Campaign Sentinel investigates one question: *why did this campaign's conversion rate change?* The causes are heterogeneous (tracking, traffic mix, landing page, data quality, conversion flow), so the next check genuinely depends on what the previous check found, which is the property that separates an agent from a fixed pipeline. The data is synthetic and reproducible with a known hidden cause per scenario, so correctness can be asserted. A second, simpler mode checks a public URL for what a URL can reveal (status, timing, content, links, tags) and says explicitly that it cannot reveal conversions.

Scope: five demo scenarios (tracking break, traffic-source decline, landing-page failure with an injected prompt, insufficient data, a tool failure) and URL checks. The agent investigates and recommends; it never changes campaigns, budgets or data.

Non-scope (recorded in the README): real ad-platform, GA4 or CRM connectors, authentication and multi-tenancy, scheduled or automatic anomaly detection, executing remediation, multi-agent systems.

## Trade-offs

- Synthetic data proves the workflow, not performance on real accounts. No business outcome or accuracy figure is claimed anywhere.
- One question keeps the product focused but leaves related jobs (pacing, fraud, creative) out.

## How verified

The five scenarios and one URL run are executed end to end by the integration tests and regenerated by `node scripts/examples.mjs`; [docs/examples/expected-outcomes.md](../examples/expected-outcomes.md) compares the hidden cause with the result of each run.
